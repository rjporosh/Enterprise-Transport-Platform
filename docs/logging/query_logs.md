# Checking Query Logs

## Overview
This document outlines how to check logs related to executed database queries.

### Steps
1. **Locate Log Files**: Find your database log files typically located in `/var/log/`.
2. **Use Command-Line Tools**: Use tools like `grep` to filter logs.
3. **Analyzing Execution Time**:
   - Look for timestamps and log entries that indicate execution time.
4. **Modify Performance**: Identify slow queries and optimize them based on patterns from logs.
